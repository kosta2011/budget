TASK-07 — Фронтенд (веб-интерфейс)
Исходное состояние:
Простая HTML-страница с формой создания транзакций, таблицей, фильтрами, балансом и аналитикой по категориям. Авторизация через всплывающее окно Basic Auth браузера (неудобно, но работало).
Что сделано:
•	Полностью переработан index.html в src/main/resources/static/ монолита.
•	Использован современный CSS (Flex, Grid, карточки, адаптивность).
•	Все API-запросы направляются через Gateway (порт 8081), что позволяет использовать единую точку входа и избежать CORS.
•	Добавлена форма логина (модальное окно) вместо стандартного всплывающего окна браузера. После успешного входа токен Authorization: Basic ... хранится в памяти и добавляется к каждому fetch-запросу.
•	Статика (HTML, CSS, JS) доступна без аутентификации, а API вызовы требуют валидного Basic Auth.
Реализованные функции:
•	Транзакции:
o	Форма создания: выбор категории (список загружается из /api/categories), сумма, тип (доход/расход), описание, дата.
o	Таблица транзакций с пагинацией и возможностью удаления.
o	Фильтрация по категории, типу и диапазону дат.
o	Выбор количества записей на странице (10, 15, 20, 50).
•	Баланс:
Блок баланса с выбором периода (дата от, дата до) и кнопкой «Показать». Отображение: доход, расход, баланс.
•	Аналитика по категориям:
Выбор периода и типа аналитики (расходы, доходы, общая). Вывод таблицы с категориями, суммами и долей в процентах, итоговая сумма.
•	AI Аналитика:
Блок с кнопками:
o	«Анализировать расходы» (POST /api/llm/analyze-my-expenses) – анализ за выбранный период.
o	«Прогноз на неделю» (GET /api/llm/predict-weekly).
o	«Совет по категории» (GET /api/llm/advice-for-category) – ввод названия категории.
o	Результат отображается в отформатированном JSON (JSON.stringify(parsed, null, 2)).
o	Обработка ошибок: если ответ не JSON, он показывается как текст.
•	Улучшения пользовательского опыта:
o	Автоматическое обновление таблицы транзакций, баланса и аналитики после создания / удаления транзакции.
o	Поддержка Basic Auth без всплывающего окна браузера (форма логина внутри страницы).
o	Адаптивная вёрстка, удобные отступы, иконки (💰, 📊, 📈, 🤖).
Технические детали:
•	Все fetch запросы используют Authorization: Basic ... (переменная authToken).
•	Для удобства чтения ответов нейросети применяется formatAiResponse.
•	Категории загружаются динамически при загрузке страницы.
Проверка:
1.	Открыть http://localhost:8081/ (Gateway).
2.	Ввести логин и пароль существующего пользователя.
3.	Создать несколько транзакций, отфильтровать, удалить.
4.	Посмотреть баланс и аналитику по категориям.
5.	Нажать кнопку «Анализировать расходы» – получить JSON отчёт от нейросети.
6.	Убедиться, что прогноз и совет по категории также работают.
